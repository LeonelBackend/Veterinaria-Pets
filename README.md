# Veterinaria Huellitas - Angular (prototipo)
## Abrir en VS Code
1. Instala Node.js compatible (según angular.dev/installation) y VS Code.
2. Descomprime la carpeta. En VS Code selecciona Archivo > Abrir carpeta.
3. En Terminal ejecuta `npm install`.
4. Ejecuta `npm start` y abre http://localhost:4200.
5. Prueba HU08 registrando atención ficticia para Luna, y consulta HU07.
6. Genera evidencias: `npm run build`, captura del navegador escritorio/móvil y commits.

### Importante
- Es un **prototipo académico**, no autentica usuarios ni aplica permisos reales.
- Utiliza `localStorage`, no servidor. No ingreses datos personales ni clínicos reales.
- HU07/HU08 son propuestas; confírmalas con el grupo antes de redactar como acordadas.
- No se han ejecutado `npm install` ni `npm run build` en el entorno donde se creó este ZIP. Verifica compilación local.
- Solo sube el proyecto al repositorio después de revisarlo; no se han realizado commits por ti.
